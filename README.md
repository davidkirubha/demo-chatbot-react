# React Chatbot

A simple and interactive chatbot application built using React. Users can send messages and receive automated responses through chatbot integration.

## 🚀 Live Demo

[React Chatbot](https://demo-chatbot-react.vercel.app)

## ✨ Features

- Interactive chatbot interface
- Send and receive messages
- React components for reusable UI
- State management using `useState`
- Automatic scrolling to the latest message
- `useEffect` for handling side effects
- `useRef` for accessing DOM elements
- Responsive chat layout

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- React
- React Hooks (`useState`, `useEffect`, `useRef`)
- Chatbot Library

## 📸 Project Overview

This chatbot allows users to enter messages and receive automated responses in a chat interface. It displays user and chatbot messages separately with profile images.
